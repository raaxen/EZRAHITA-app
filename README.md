# 🎶 EZRAHITA-app

> Application mobile de gestion d'une chorale.

EZRAHITA-app est une application mobile conçue pour centraliser et simplifier la gestion quotidienne d'une chorale.

L'application permet notamment de gérer les membres, les finances, les projets, les événements et les annonces depuis une seule interface.

---

## 📱 Aperçu du projet

L'objectif est de créer une application moderne, simple et intuitive permettant aux responsables de la chorale et aux membres d'accéder facilement aux informations qui les concernent.

### Fonctionnalités principales

- 👥 Gestion des membres
- 💰 Gestion des finances
- 📊 Suivi des revenus et dépenses
- 📁 Gestion des projets
- 📢 Gestion des annonces
- 📅 Gestion des événements
- 🖼️ Galerie photos des événements
- 👤 Gestion des profils
- 🔐 Authentification et gestion des rôles
- 📈 Tableau de bord avec statistiques

---

# 👥 Gestion des membres

Chaque membre possède un profil contenant notamment :

- Nom et prénom
- Photo de profil
- Sexe
- Date de naissance
- Âge calculé automatiquement
- Année d'entrée dans la chorale
- Voix
  - 1er
  - 2ème
  - 3ème
  - Basse
- Statut du membre

Les responsables pourront ajouter, modifier ou supprimer des membres.

---

# 💰 Gestion financière

L'application permet de suivre les finances de la chorale.

### Revenus

Exemples :

- Cotisations
- Dons
- Participations
- Autres revenus

### Dépenses

Exemples :

- Achat de matériel
- Transport
- Location
- Nourriture
- Événements
- Instruments
- Autres dépenses

L'application permettra notamment de :

- Enregistrer une transaction
- Consulter l'historique
- Suivre les paiements des membres
- Associer une dépense à un projet
- Calculer automatiquement le solde
- Consulter les statistiques financières

> Le solde sera calculé à partir des transactions enregistrées afin d'éviter les incohérences.

---

# 📁 Gestion des projets

Les projets de la chorale pourront être suivis directement depuis l'application.

Chaque projet pourra contenir :

- Nom du projet
- Description
- Budget prévu
- Montant dépensé
- Montant restant
- Date de début
- Date de fin
- Statut
- Dépenses associées

Exemples :

- Achat de nouveaux microphones
- Achat d'instruments
- Organisation d'un concert
- Voyage de la chorale

---

# 📢 Annonces

Les responsables pourront publier des annonces à destination des membres.

Une annonce pourra contenir :

- Titre
- Description
- Date de publication
- Importance
- Auteur

Les membres pourront consulter les annonces depuis leur application.

---

# 📅 Événements

L'application permettra de gérer les différents événements de la chorale :

- Répétitions
- Concerts
- Sorties
- Réunions
- Activités diverses

Chaque événement pourra contenir :

- Nom
- Description
- Date
- Heure
- Lieu
- Photos

---
